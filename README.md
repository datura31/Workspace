# WorkBuddy 个人工作台（PWA）

一个纯前端的个人工作台 PWA 应用：计划、记账、运动饮食、考试学习、数据分析、创作者中心一站式管理。可安装到手机桌面，**离线也能用**，所有数据保存在本地。

## ✨ 功能模块

1. **功能工作台主页** —— 今日任务、简易日历、减脂运动记录卡片
2. **个人计划** —— 中长期计划 + 每日任务（增 / 删 / 勾选完成）
3. **每日记账功能** —— 收支录入、流水列表，新增 / 删除
4. **收支统计看板** —— 饼图（分类占比）+ 柱状图（月度趋势）+ 汇总卡片
5. **减脂运动和饮食记录** —— 运动记录、早中晚三餐热量（增 / 删）
6. **成功日记** —— 日记新增、历史列表、删除
7. **日历** —— 完整月视图，事件标记的新增 / 删除
8. **央国企考试学习** —— 进度总览、待学任务、高频考点（增删改）、刷题记录、笔记
9. **数据分析学习** —— 课程清单、知识点卡片（增删改）、练习记录、笔记
10. **创作者中心** —— 数据概览、选题库、创作待办、草稿笔记
11. **个人工作台设置** —— 主色切换（蓝/绿/紫/橙）、明暗模式、个人信息、一键重置、JSON 备份导出/导入

## 🧩 技术特性

- **纯前端**：无任何后端接口，全部使用静态模拟数据
- **PWA**：`manifest.json` + `service-worker.js`，支持安装到桌面、离线打开
- **本地持久化**：`localStorage` 存储，刷新浏览器数据不丢失
- **响应式**：PC 端左侧固定导航；手机端自动变为汉堡折叠侧边菜单
- **可换肤**：4 种主色 + 浅色 / 暗黑模式实时切换

## 💻 本地预览

直接用浏览器打开 `index.html` 即可使用（数据正常，但 PWA 安装 / 离线需在 HTTPS 环境）。

如需本地起服务（更接近真实环境）：

```bash
# 在项目目录下执行
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 🚀 部署到 GitHub Pages

1. 在 GitHub 新建仓库（建议 Public），仓库名例如 `workbuddy-pwa`
2. 把上述文件**直接上传到仓库根目录**
3. 进入仓库 **Settings → Pages**
4. **Source** 选 `Deploy from a branch`，**Branch** 选 `main`，**folder** 选 `/ (root)`
5. 保存后等待 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

（仓库名若起为 `<用户名>.github.io`，则地址为 `https://<用户名>.github.io/`）

## 📱 添加到手机主屏幕（当 App 用）

部署后，用手机浏览器打开上面的 GitHub Pages 地址，**必须是通过 https 打开**。

**安卓（Chrome / Edge）**
1. 打开页面 → 点右上角 `⋮` 菜单
2. 选 **「安装应用」/「添加到主屏幕」**
3. 确认后桌面出现图标，点开即全屏、无地址栏

**iPhone / iPad（Safari）**
1. 打开页面 → 点底部中间 **「分享」按钮**（⬆️ 方框箭头）
2. 向上滑找到 **「添加到主屏幕」**
3. 命名后「添加」，桌面生成图标，打开即全屏 App

## 💾 数据说明

- 所有数据保存在浏览器 `localStorage`，**同一浏览器 / 同一设备**刷新不丢失
- 换浏览器或清缓存会回到默认模拟数据
- 设置页提供 **一键重置全部数据**，以及 **导出 / 导入 JSON 备份**
- 重置仅清空本地数据，不影响已部署的应用本身

## ⚠️ 注意事项

- PWA 安装与离线功能仅在 **HTTPS**（或 `localhost`）下生效；`file://` 直接打开只能浏览
- 菜单类操作（新增 / 删除 / 勾选）会立即写入本地存储并更新界面
